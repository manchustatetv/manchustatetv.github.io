# 满洲国电视台 Manchu State TV

MSTV Uploader 是满洲国电视台内部使用的上传工具，仅用于把本台自制的新闻节目以“私享（private）”方式上传到本台自有的 YouTube 频道。

MSTV Uploader is an internal tool of Manchu State TV. It only uploads our own news programs as private videos to our own YouTube channel via the YouTube Data API.
